# Практическая работа №2 — CSS, адаптивная верстка и SCSS

## Описание
Адаптивный каталог учебных товаров. Данные загружаются из `catalog.csv`, цвета и отступы берутся из `theme.json` и перенесены в SCSS-переменные. Реализована фильтрация по категориям и адаптивная сетка на CSS Grid.

## Технологии
- HTML5 (семантическая разметка)
- SCSS (переменные, миксины, партиалы)
- CSS3 (Grid, Flexbox, медиазапросы)
- JavaScript (Fetch API, DOM, фильтрация)
- Git

## Как запустить локально
1. Клонировать репозиторий.
2. Открыть папку в VS Code.
3. Установить расширения: Live Server и Live Sass Compiler.
4. Нажать внизу VS Code кнопку "Watch Sass" (чтобы собрался CSS).
5. Нажать правой кнопкой мыши на `index.html` и выбрать "Open with Live Server".

## Структура
- `index.html` — разметка.
- `scss/` — исходные SCSS-файлы (`_variables`, `_base`, `_layout`, `styles`).
- `scss/styles.css` — скомпилированный CSS.
- `script.js` — логика загрузки и фильтрации.
- `dataset/` — исходные данные (`catalog.csv`, `theme.json`).

## Чем SCSS отличается от CSS custom property?
SCSS-переменные (`$accent`) обрабатываются на этапе компиляции и не попадают в итоговый CSS. CSS-переменные (`--accent`) живут в браузере и могут меняться через JS (например, для смены темы). 
**Зачем нужны partial-файлы?** Они позволяют разбить код на логические части (`_variables`, `_layout`) и подключать их в главный файл, не раздувая его.
**Где применен mixin?** Миксин `@mixin card-style` используется для единообразного оформления карточек и панели фильтров.
